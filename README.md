# nixpkg-filmcraft

Nix package for [ArtCraft FilmCraft](https://github.com/storytold/filmcraft), using its official Linux x86_64 release archive. The package installs the app directly; it does not include the ArtCraft launcher or provide an auto-updater.

Pinned upstream release: `v0.12.0`.

```sh
nix build
nix run
```
